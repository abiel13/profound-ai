# ProFund AI

One-click fundraising dashboard for Pro Youth Foundation.
Works on PC, on your phone over Wi-Fi, and as a public shareable link.

---

## ☁️ Deploy to Railway (live URL) — 2 clicks

1. In Emergent chat, click the green **"Save to GitHub"** button → pick a repo name (e.g. `profund-ai`).
2. Open [railway.app](https://railway.app) → **New Project** → **Deploy from GitHub repo** → pick the repo you just created.

Railway detects `Dockerfile` + `railway.json` automatically, builds the image (~5 min on the first run), and gives you a public URL. The same URL serves:

- `/`         → React frontend
- `/api/*`    → FastAPI backend
- `/docs`     → Swagger / OpenAPI explorer

Login: `admin@profund.ai` / `ProFund2026!` (auto-seeded on first boot).

Optional Railway settings (defaults already work):

| Variable | Default | Override when… |
|---|---|---|
| `ADMIN_EMAIL` | `admin@profund.ai` | you want a different admin email |
| `ADMIN_PASSWORD` | `ProFund2026!` | you want a different admin password |
| `JWT_SECRET` | autogenerated | you want a fixed secret |
| `EMERGENT_LLM_KEY` | empty | you want AI features (Grant Scanner, TikTok pack, Email Drafts) |
| `LOCAL_ONLY` | `0` | you want to lock the app to localhost (don't set on Railway) |

## ⚡ Start on PC (Windows) — recommended

1. Extract the ZIP anywhere on your PC.
2. **Double-click `Start ProFund AI.vbs`.**

That's it. The app opens automatically in your browser — no terminal, no commands.
First launch auto-installs everything in the background (≈ 60–90 sec) behind a small splash screen.
Every launch after that is instant (≈ 2 sec).

The first time only, Windows may ask to install **Python** and **Node.js** —
the launcher will open the right page for you. Both are free, take 2–3 minutes,
and are needed once.

To stop the app cleanly: **double-click `Stop ProFund AI.vbs`**.

**Login**
```
Email:    admin@profund.ai
Password: ProFund2026!
```

## 📱 Open from phone (same Wi-Fi)

When `start.bat` finishes it prints a line like:
```
Phone   http://192.168.1.42:3000
```
Open that on your phone. If it doesn't connect, let Windows Firewall allow
inbound TCP **3000** and **8001** on the **Private** network.

## 🌐 Share a public live link

With `start.bat` already running, **double-click `start-public.bat`**.
It downloads Cloudflare Tunnel (no signup), creates two tunnels, and prints
one ready-to-share URL like:
```
https://abcd.trycloudflare.com/?api=https://efgh.trycloudflare.com
```
That URL is also saved to **`LIVE_LINK.txt`**. Share it with anyone.
Close the `PFA ... Tunnel` windows to stop the public link.

## 🤖 AI features

The two Wizard features (Analyze Grant, Generate Documents) and the V11
Campaign/Sponsor generators need an Emergent LLM key.

- Without a key → the app still runs, non-AI features work normally, and
  AI pages show a clear "AI not configured" message.
- With a key → edit `backend/.env`, set `EMERGENT_LLM_KEY=<your-key>`,
  restart the backend window. Get a key at <https://emergent.sh/profile>.

## 🆘 If something breaks

- **Nothing happens when I double-click `start.bat`** — open the file in
  File Explorer → right-click → *Run as administrator* once. Windows
  sometimes blocks fresh .bat files.
- **"invalid email or password"** — the backend re-syncs the password from
  `backend/.env` on every start, so restart the backend window once. Or
  run `cd backend && python reset_admin.py`.
- **Port already in use** — close any previous ProFund windows, or any
  other app using ports 3000 / 8001, then run `start.bat` again.
- **Backend window shows a Python error** — take a screenshot of the
  window and send it. Don't close it — that's where the real error is.

## What's in the app

- V1–V10: grants search, AI scoring, wizard (6-step), batch apply, donor
  CRM, follow-ups, command center, weekly intelligence reports
- V11: 3-Mode Funding Engine — Small Donor Campaigns ($5–$50), Sponsor
  Offers ($100–$1000), Payment Links with UTM, Send Queue (approval
  flow), Donations tracking

Backend = FastAPI + SQLite file (no DB server).
Frontend = React + Tailwind + shadcn/ui.
